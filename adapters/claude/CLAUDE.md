## 何时启用

用户要求造世界 / 宇宙 / 星球并设定其底层物理化学生物法则；设计非地球物理（双恒星、反向重力、无水生命）；审查架空设定自洽性；生成可旋转 3D 星球预览。

## 启用步骤

1. **完整读** `{{PANGU_ROOT}}/SKILL.md`。
2. 依其指引按需读 `references/`（渐进披露）。
3. 脚本用绝对路径：

```bash
python "{{PANGU_ROOT}}/scripts/pangu.py" doctor
```

## 四条不可违反

1. 先立律，后长物（物理层未定稿不提生物文明）
2. 三律：逆行 / 代价 / 痕迹
3. `world.json` 单一数据源，生成物禁止手改
4. 产物落 `./out/<id>/`，不污染技能目录
