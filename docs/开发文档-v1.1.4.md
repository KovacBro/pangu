# 盘古 1.1.4 开发文档 · 观测层

> 1.1.3 的文档在 `docs/开发文档-v1.1.3.md`。这份只讲 1.1.4 加的东西，以及**为什么只加这些**。

---

## 1. 目标：把「第一眼」从文本变成可算的东西

1.1.3 收到的评论里最狠的一条是：「第一眼。我希望看到星星就足够了。」

问题不在美学，在**结构**：`cosmology.sky_phenomena` 是一串自由文本，写「远灯是不灭的橙红小点」没人拦着。1.1.1 有地、1.1.2 能改、1.1.3 知道走到哪，但没有任何一层能回答：**这里的居民抬头，到底看见什么？**

1.1.4 只做这一件事，且**不引入任何新物理**。观测点、自转与倾角、大气成分与气压、恒星的光度、距离与轨道相位、卫星半径与轨道——这些字段 1.1.3 就已经写在 `world.json` 里了，只是没人把它们串起来算过。

一条自我约束：**不加字段，只加解释。** `starfield`、`sky`、`orbit.phase_deg` 全部可选，缺省即默认；旧的 `world.json` 什么都不改也能跑 `sky`。

## 2. 模型

四个子模型，全部标「简化」：

### 2.1 星表：程序生成，不接真实星表

```
参数 = (seed, count, magnitude_dist, color_mix, galaxy)
hash = sha1(json(参数))[:8]
```

- 光度分布用累积幂律：`N(<m) ∝ 10^(0.45 m)`，`m ∈ [−1.5, 6.5]`，反解 `u ~ U(0,1)` 得星等。
- 位置：球面均匀；若 `galaxy.present`，其中 `0.35 × brightness` 比例的星改撒在银道面（银纬取高斯，银经均匀），并整体压暗 1.6 等——银河是「密集暗星的叠加」，不是贴图。
- 颜色按 `color_mix` 抽光谱型，映射到 `O/B/A/F/G/K/M` 的色温色。
- `random.Random(seed)` 的 Mersenne Twister 跨版本稳定，所以 `hash` 相同 ⇒ 星表逐字节相同。`sky --check` 的 S01 就是拿这条做复算。

**为什么不接 HYG / Gaia**：数据体积（HYG 约 20 MB）、许可、以及一句设定——「这是**这个世界的**星表」。接真实星表等于承认所有世界共用一片天。

### 2.2 天球：圆轨道 + 标准地平坐标

- 行星在黄道面：`φ(t) = π + 2π·(t/24)/P_planet`；恒星同法，相位取 `orbit.phase_deg`。
- 观测者 → 恒星的方向 `d = R_star − R_planet`，转赤道坐标（倾角 `ε` 绕 x 轴转），得 `(ra, dec)`。
- 本地恒星时 `LST(t) = 180° + 360°·t/day_hours`（`t=0` 为**本地午夜**，主星在下中天）。
- 高度角 / 方位角走标准公式：

```
sin h = sinφ·sinδ + cosφ·cosδ·cos H
A     = atan2(cosδ·sin H, sinδ·cosφ − cosδ·sinφ·cos H)
```

- 视星等 `m = −26.74 − 2.5·log10(L/L☉) + 5·log10(d_AU)`。
- 大气消光 `Δm = 0.20·(1/sin h − 1)`，地平附近按 `1/sin h` 放大。

**不算什么**（写在输出里）：视差、光行时、轨道偏心率、日月食与凌日、行星逆行、折射。

### 2.3 天光：经验模型（±0.5 等）

单位统一用 `mag/arcsec²`，**数值越小越亮**。分量叠加走线性通量：

```
B_total = −2.5·log10( Σ 10^(−0.4·B_i) )
```

| 分量 | 规则 |
|---|---|
| 空气辉光 | 21.9（暗空基线） |
| 暮光 | 真太阳（m < −20）在地平线下 < 18° 时，从 13.0 线性退到 21.9；在地平线上即 13.0 |
| 明亮点光源 | m < −10 的天体（远星、巨月）：两点标定「日面 −26.74 → 13.0、满月 −12.7 → 18.0」线性插值；张角 < 10′ 再加 2.5 等（点源散射弱于面源） |
| 尘埃散射 | 气压每高出 1 个地球大气，整体抬亮 0.40 等 |
| 极限星等 | `6.5 − 0.9·(21.9 − B)`，钳在 1.0–6.5 |
| 银河可见 | `galaxy.present ∧ B ≥ 21.0 ∧ brightness ≥ 0.3` |

**这套常数的来历**：21.9 与 6.5 是 Bortle 1–2 的公开观测值；13.0 与 18.0 是「白天 / 满月夜」的两个锚点；0.9 等/mag 来自「天光亮 1 mag，可见星等降 0.5–1 等」的经验区间。**没有一个数是从天体物理第一性原理推出来的**，所以输出里永远写「经验模型 ±0.5 等」。

### 2.4 昼长：解析解，不是数值积分

```
δ(d) = ε·sin(2π·d/year)          # 第 0 天取春分
cos H0 = −tanφ·tanδ              # |cos H0| > 1 即极昼 / 极夜
昼长 = 2·H0/360 · day_hours
```

赫利孔：`φ=12°、ε=18.2°、day=31.4 h` → 昼长 **15.0–16.4 h**，与手算一致。倾角 0° → 全年 `day_hours/2 = 15.7 h`。极昼极夜按**月内细扫**判定（只看月中会漏掉至日那几天）。

## 3. 数据结构

```jsonc
"cosmology": {
  "starfield": {                      // 全部可选
    "seed": 7, "count": 12000, "magnitude_dist": "power-law",
    "color_mix": {"K": 0.2, "G": 0.5, "F": 0.2, "M": 0.1},
    "galaxy": {"present": true, "inclination_deg": 32, "width_deg": 18, "brightness": 0.6},
    "constellations": [],
    "hash": "f23c9fe2"                // sky --write --yes 生成
  },
  "sky": {                            // sky --write --yes 生成，不要手填
    "summary": {"limit_mag": 3.94, "visible_stars": 219,
                "sky_brightness": 19.05, "milky_way": false,
                "moment": "夜半", "note": "…", "generator": "sky/1.1.4"},
    "checks": [{"id": "S01", "status": "pass"}, …],
    "figures": []
  }
}
```

`bodies[].orbit.phase_deg` 为 1.1.4 新增可选字段（卫星相位，缺省 0）。

## 4. 命令

```bash
python scripts/pangu.py sky world.json                      # 今夜五段
python scripts/pangu.py sky world.json --at "日落后 2h"      # 相对时刻
python scripts/pangu.py sky world.json --at "双星合前 30m"   # 合（最小角距）前 30 分钟
python scripts/pangu.py sky world.json --year               # 逐月昼长表
python scripts/pangu.py sky world.json --month 3            # 只看一季
python scripts/pangu.py sky world.json --allnight           # 一夜六帧
python scripts/pangu.py sky world.json --check              # S01/S02/S03
python scripts/pangu.py sky world.json --md out/今夜.md      # PNG + Markdown
python scripts/pangu.py sky world.json --json               # agent 用
python scripts/pangu.py sky world.json --write --yes        # 回写 hash 与摘要
python scripts/pangu.py whatif world.json --set "cosmology.bodies[0].axial_tilt_deg=80" --sky
```

`--at` 四种写法：`"22:10"`、`"day=12,hour=22"`、`"日落后 2h"`（扫一天找主星下落时刻）、`"双星合前 30m"`（扫一天找两星最小角距）。缺省是**夜半**。

### 4.1 五段输出

```
【今夜】世界名 · 夜半 ｜ 观测点 12°N ｜ 天空亮度 / 极限星等 / 可见星 / 银河
【全天】96×30 地平坐标星图（底边地平线，顶为天顶，#*+. 按星等分档）
【关键天体】每颗恒星与卫星的 alt / az / 视星等 / 距离
【一年】昼长区间、极昼极夜、最长夜
【判断】一句话结论 + 「简化模型」声明
```

### 4.2 图

- ASCII：96×30，零依赖，随 `sky` 默认输出，**终端里就能看**。
- PNG：1200×900，全天鱼眼（天顶在圆心，N 在正上方），走 `png_writer`，零依赖。银河按银道面撒 9000 个半透明点。
- 预览页：`frames_for_preview()` 预算 6 帧（每帧最多 1400 颗星），页面只负责画，**不在浏览器里复算天体**。

## 7. 已知限制（都写在输出里）

1. **天光是经验模型**，误差 ±0.5 等；不建模大气散射相函数、臭氧吸收、气溶胶的波长依赖。
2. **圆轨道近似**：不算偏心率、视差、光行时、日月食、凌日、行星逆行。
3. **星表是程序生成的**：不是 Gaia/HYG，也不能反推「这个世界的真实宇宙」。它只保证「同一参数 → 同一片天」。
4. **一个观测点**：`sky` 只算 `surface.observer` 那一处；经度不进入天球几何（同一本地时刻，全世界看见同一片天）。
5. **只报不改**：`sky --check` 发现「文本说它是小点，实算 −16 等」时给软提示，改光度还是改写法由作者决定。
6. **不生成星座神话**：`constellations` 只接受手写的 `[[ra, dec], …]` 连线，引擎不替你想故事。

## 8. 第二批：对着真实世界（同日增补）

第一批回答「好看吗」，第二批回答「**算得对吗**」。

### 8.1 `benchmark earth`

六条曲线：纬向年均温（GISS 分区平均）、纬向年降水（GPCC）、昼长（对 720 步独立数值积分）、逃逸速度、平衡温度、陆地 NPP。输出「目标 / 实测 / 结论」，进 `review` 的 **D9**。

**它是回归网，不是装饰**。建表第一次跑就 4/6，抓出两个真错：

| 现象 | 根因 | 修法 |
|---|---|---|
| 极地降水 3 mm/yr（实际 150） | 蒸发 `if temp < 268: continue`，一刀切归零 | `max(0, T−250)/30` + 背景源 |
| 25° 比赤道还湿 | Hadley 下沉支没建模 | `k × (1 − 0.55·exp(-((\|lat\|−28)/11)²))` |

修完 **6/6**：纬向降水 r = 0.817、纬向温度 RMSE 6.72 K、昼长 RMSE 0.023 h。

### 8.2 温室

`ΔT = 33 + 4.28·ln(CO₂e/560)`，`CO₂e = CO₂ + 28·CH₄ + 265·N₂O + 23 500·SF₆ + 0.5·H₂O`（ppmv），再乘 `(P/101.325)^0.15`。

- `4.28 = 0.8 K/(W/m²) × 5.35 W/m²`，所以 **CO₂ 翻倍 = +2.97 K**，与 AR6 最佳估计 3.0 K 对齐。
- 声明值 `greenhouse_delta_k` **优先**：旧世界零影响。
- 两者差 > 15 K 时在 `export` 里点名（赫利孔：声明 33 K / 估算 55 K），**只报不改**——那是设定决策。

### 8.3 承载力

`NPP = min(f(T), f(P))`（Miami），×0.475 转碳；`人口 = NPP × 采收率 × 9 kcal/g ÷ (2500×365)`。

星夜 → 56.5 Gt C/yr → 约 55.8 亿人。假设全写在 `biology.carrying_capacity.assumptions` 里，**删掉假设等于把结论变成许愿**。

### 8.4 季节

`map --season` 用赤纬 ±倾角重跑同一套气候模型。两处口径：

- 温度振幅压到年增益的 45%（62 K → 28 K）：海温滞后与热惯性没建模，按全年增益直接推会给出 70 K+ 的年较差。
- 风带整体随热赤道移动（`lat − dec×0.6`），所以 ITCZ 会跟着走——北半球夏季降水 1457 mm、冬季 391 mm。

### 8.5 没做

板块速度、时间轴、洋流环流、冰川-反照率反馈、生物尺寸判据。它们仍在 `docs/1.1.4-更新方案.md` §15.5 的 P1/P2 里。

## 9. 为什么不做

| 想到过 | 为什么没做 |
|---|---|
| 接真实星表（HYG/Gaia） | 20 MB 数据 + 许可 + 一句设定（「这是这个世界的星表」） |
| 实时 3D 天球 | 预览页已有 3D 行星；再塞一个 WebGL 天球，首屏会掉帧，且 Canvas 2D 足够讲清「有几颗、亮不亮」 |
| 日食 / 凌日 / 行星逆行 | 需要偏心率、倾角与相位同时精确，误差比结论大；留给 1.1.5 的 `sky --events` |
| 把 `sky` 写进 G1–G6 门槛 | 6/6 是 1.1.3 的口径，加一项会让所有旧世界从 6/6 掉到 6/7；宁可做软提示 |
| 自动改 `sky_phenomena` | 天象文本是设定，不是派生量。引擎只负责把矛盾指出来 |
