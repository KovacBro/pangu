# 3D 预览层设计规范

> 一句话：**把 `world.json` 变成一个能用鼠标转起来的世界，而不是一张渲染图。**
> 预览层不追求天文级精度，追求"抬头一看就信了"。

## 1. 目标与非目标

**目标**
- 多恒星系统中，能直观看出"两个太阳"的相对位置、颜色差异、互绕运动
- 行星表面能体现 `biomes` 的分布逻辑与 `atmosphere` 的色调
- 昼夜明暗线由**真实光源方向**驱动，而非贴图假造
- 单个 HTML，双击即开，无需服务器、无需构建

**非目标**
- 不表示真实尺度比例（数量级差 5 位以上，同屏无意义）
- 不做大气散射的物理精确解（用近似 fresnel + 兰伯特）
- 不做地形起伏的真实高程（用噪声位移，仅供观感）
- 不做行星表面第一人称行走（1.0 不做，见路线图）

## 2. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 渲染库 | Three.js r160（ESM） | 生态成熟，单文件即可 import |
| 加载方式 | `import()` 动态，多 CDN 回退 | 规避 importmap 单源锁定问题 |
| 控制器 | **自研 `OrbitLite`**（~70 行） | three 的 OrbitControls 走 `three/addons`，依赖 importmap 解析裸模块名，动态回退时会崩。自研可完全解耦 |
| 纹理 | 全部**程序化生成**（GLSL 噪声 / CanvasTexture） | 零外部资源，永不 404 |
| 打包 | 单个 `.html`，JSON 内联 | 可离线、可邮件、可丢进任何静态托管 |
| 依赖 | 0 个 npm 包 | — |

### CDN 回退链

```js
const CDN = [

  "https://cdn.jsdelivr.net/npm/three@0.160.0",
  "https://fastly.jsdelivr.net/npm/three@0.160.0",
  "https://esm.sh/three@0.160.0"

// 依次 await import(base + "/build/three.module.js")，首个成功即用
// 全失败 → 显示降级页（世界数据以文字呈现 + 说明如何本地放 three.module.js）
```

**降级页不是白屏**。它必须展示：世界名、三律摘要、天体表、`sky_phenomena`。用户即使看不到 3D，也要拿到信息。

## 3. 场景图结构

```
Scene
├── starfield            Points，5000 颗，球壳半径 900，无衰减
├── systemRoot           所有天体母节点（受时间驱动旋转）
│   ├── star_A           Mesh(球) + Sprite(辉光) + PointLight
│   ├── star_B           Mesh(球) + Sprite(辉光) + PointLight
│   ├── star_C (可选)
│   ├── orbitLine_A      LineLoop（椭圆/圆）
│   ├── orbitLine_B
│   ├── body_<id>        Group
│   │   ├── surface      Mesh(球, 自定义 ShaderMaterial)
│   │   ├── cloud        Mesh(球 ×1.015, 半透明噪声)
│   │   ├── atmosphere   Mesh(球 ×1.06, BackSide, Additive)
│   │   ├── ring (可选)  Mesh(RingGeometry, 双面)
│   │   └── moon_<id>    Group（递归，可再带子卫星）
│   └── orbitLine_<id>
└── Lights
    ├── ambient          AmbientLight(0x0a0d14, 0.35)
    └── per-star PointLight（上限 4）
```

**层级规则**：`star.orbit.parent` 或 `body.orbit.parent` 指向另一个天体 id 时，该节点挂到父节点下，用相对坐标；指向质心标签（如 `AB`）时，挂 `systemRoot`，绕原点公转。

## 4. 尺度系统（双尺度）

真实比例不可同屏，采用两套独立尺度：

```
轨道半径（场景单位） = a_au × ORBIT_SCALE        ORBIT_SCALE = 26
天体半径（场景单位） = visual_radius（缺省见下）
                        缺省 = clamp(1.0 + 1.5 × log10(radius_earth + 1), 0.6, 6.0)
恒星半径             = clamp(1.4 × radius_solar^0.7, 0.8, 4.0)
```

- 同一 `parent` 下的多个子体，轨道半径统一按 `a_au` 缩放，保证**相对关系正确**
- 天体半径按对数压缩，保证**大小对比可读**
- HUD 右下角固定标注：`示意视图 · 天体与轨道非真实比例`

**卫星保护**：卫星轨道若因 `a_au` 太小而与母星穿模，自动抬到 `母星半径 × 2.2`。

## 5. 着色器设计

### 5.1 行星表面（核心）

**顶点**
```glsl
varying vec3 vObj;    // 物体空间坐标（噪声取值，随自转转动）
varying vec3 vN;      // 世界法线
varying vec3 vW;      // 世界位置（算光源方向）
```

**片元流程**
```
1. 噪声：h = fbm(vObj × uNoiseScale, 5 层)
2. 山脉：h += 0.35 × ridged(vObj × uNoiseScale × 2.7)
3. 归一化到 0–1，按 uSeaLevel 与 biome stops 插值取色
4. 极冠：lat = |normalize(vObj).y|，smoothstep 混合 uPolarColor
5. 多光源：for each sun → L=normalize(pos - vW)，diff = max(dot(N,L),0)
   累加 color × intensity × (diff×0.92 + diff²×0.08)
6. 加环境光；高光：海面区域用 Blinn-Phong 弱反射
7. 输出
```

**生物群系插值**：`uBiomeStop[]` 为升序的 0–1 阈值，`uBiomeColor[]` 对应颜色。取 h 落在哪两个 stop 之间，`mix` 两色。最多 8 个群系，超出由 `pangu.py` 截断并警告。

**为什么用物体空间噪声**：贴图随球体一起转，自转才看得出来。用世界空间会导致"纹理不动、球在转"的错觉。

### 5.2 大气辉光

```glsl
// 背面渲染，AdditiveBlending，不写深度
float rim = pow(1.0 - abs(dot(normalize(vN), normalize(vViewDir))), 2.6);
// 再乘一个"朝向光源"的增益，让阳面边缘更亮
gl_FragColor = vec4(uAtmoColor, 1.0) * rim * uAtmoStrength;
```

### 5.3 云层

`alpha = smoothstep(0.45, 0.75, fbm(vObj × 3.0 + uTime×0.01))`，颜色取 `mix(阴影蓝灰, 阳光白, 光照系数)`。云比地表转得略快（`rotation × 1.12`），制造大气环流错觉。

### 5.4 恒星

- 球体：`MeshBasicMaterial`（不受光，永远全亮），颜色 `star.color`
- 辉光：`Sprite` + `CanvasTexture`（径向渐变，`rgba(255,255,255,1) → 0`），`AdditiveBlending`
- 光晕层数：2 层，内层 1.6R，外层 4.5R，营造恒星大气的弥散感

### 5.5 星空

`BufferGeometry` + `Points`，5000 个随机方向 × 半径 900 的球壳点；`size` 随机 0.6–1.8，`sizeAttenuation: false`，颜色轻微色温抖动（蓝白到橙）。

## 6. 光照模型

- 每颗恒星一个 `PointLight`，强度 ∝ `luminosity_solar`（对数压缩：`0.4 + 0.9×log10(L+1)`）
- 行星着色器**自己算光照**（不靠 `PointLight`），因为双光源需要精确的逐像素叠加；`PointLight` 只用于卫星与环等标准材质
- 双星色温不同 → 交接处的明暗线上会自然出现**两色过渡带**，这是本预览层最重要的视觉特征（对应"双影"设定）
- 环境光极低（0.35），保证夜面近乎全黑，可见星空

## 7. 交互与视图

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 绕焦点旋转（theta/phi，限 phi ∈ [0.05π, 0.95π]） |
| 滚轮 | 缩放（radius，限 8–420） |
| 点击天体 | 切换焦点到该天体，相机平滑过渡 |
| `Space` | 暂停 / 继续 |
| `1` `2` `3` | 系统视图 / 主角天体视图 / 星系远景 |
| `R` | 重置视角 |
| `H` | 显隐 HUD |

**视图定义**
- **系统视图**：相机距原点 ≈ 主角轨道半径 × 2.2，俯角 28°
- **天体视图**：相机距天体 ≈ 该天体半径 × 3.4，略高于赤道
- **远景**：距原点 ≈ 最长轨道 × 3.5，俯角 55°，看整体层级

**相机过渡**：球坐标线性插值，`t` 用 `easeInOutCubic`，时长 0.9 s。拖拽时立即打断插值。

## 8. 时间系统

单一全局 `t`（秒），每帧 `t += dt × speed`。

```
公转角速度 ω = 2π / period_days × TIME_BASE      TIME_BASE 使最短轨道 ≈ 24 s 一圈
自转角速度   = 2π / (rotation_hours/24) × TIME_BASE × 8
```

- `speed` 档位：0.25 / 1 / 4 / 16，默认 1
- 潮汐锁定（`rotation_hours == null`）：自转角速度 = 公转角速度
- 恒星互绕：`star.orbit.a_au` 存在的星体绕质心（原点）公转，用同一 `t`

## 9. 性能预算

| 项 | 预算 |
|---|---|
| 三角面总数 | < 120k（球体 64×64 ≈ 8k 面/个，≤ 8 个天体） |
| Draw call | < 40 |
| 目标帧率 | 60 fps @ 1080p；≤ 30 fps 时自动降 `pixelRatio` 到 1 |
| 首屏时间 | < 2.5 s（不含 CDN） |

**降级顺序**：星空点数 5000→1500 → 云层关闭 → 大气关闭 → 球体分段 64→32。

## 10. 数据契约

预览层只读以下字段，缺省时用默认值，**不报错**：

| 字段 | 缺省 |
|---|---|
| `meta.name` | `未命名世界` |
| `meta.aesthetic` | `["#8899aa"]` |
| `cosmology.stars[].color` | 按 `temp_k` 近似（`<3700` 橙红，`<5200` 橙黄，`<6000` 白，`<7500` 白蓝，else 蓝） |
| `cosmology.bodies[].biomes` | 单色 `#7a8a7a` |
| `atmosphere.color` | `#88bbdd` |
| `rotation_hours` | 24 |
| `visual_radius` | 见 §4 |

**容错要求**：JSON 缺段、字段类型错误、`bodies` 为空，都必须渲染出"有空星球 + 提示条"，不能白屏。
