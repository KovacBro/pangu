## 1. 范围：并进来的是什么，不是什么

这一版把路线图上的九个模块并了进来，但**并的是内核，不是全耦合模式**。判据是「能不能被一条解析解或一个公开数推翻」，不是「能不能跑出漂亮图」。

| 路线图版本 | 主题 | 1.1.5 做到了什么 | 没做到什么 |
|---|---|---|---|
| 1.1.5 | 守恒与误差 | 四本账、量纲硬域、± 传播、certify、replay | — |
| 1.2 | PDE 内核 | 一维热传导 / 平流 / 浅水，全部对解析解 | 二维/三维、自适应网格、隐式推进 |
| 1.3 | 环流 | 一维 Budyko–Sellers 能量平衡 + 冰-反照率分岔 | 原始方程、季风、风暴路径、海冰动力学 |
| 1.4 | 辐射 | 灰体两流 + 水汽反馈（τ 三分解） | k-distribution、谱线表、云微物理、光化学 |
| 1.5 | 固体地球 | 瑞利数、板块速度、地幔热流的边界层标度 | 地幔对流求解、流变、俯冲、地磁发电机 |
| 1.6 | 轨道与恒星 | 辛积分、一阶后牛顿进动、潮汐去旋 | N 体长期演化、共振捕获、恒星演化轨迹 |
| 1.7 | 物质与化学 | 碳-硅酸盐恒温器（CO₂–T–风化一个回路） | 矿物相平衡、反应-输运、C/N/P/Fe/S 循环 |
| 1.8 | 生命 | Hubbell 中性群落 + Ewens 抽样 + 10% 定律 | 遗传、代谢网络、食物网动力学、ABM |
| 1.9 | 文明 | — | 全部（人口上限仍是 NPP 折算） |
| 1.10 | 耦合与性能 | 八个内核共用一套 `demo()/report()` 与 CLI 入口 | 统一时间步、数据总线、增量重算 |
| 2.0 | 可证伪交付 | `certify` 适用域声明 + 覆盖率 + 基准偏差 | 第三方复算协议、误差表覆盖 100% |

## 2. 八个内核（`scripts/*.py`）

统一约定：

```python
def demo() -> dict:      # 返回 {"ok": bool, "detail": {...}, ...}
def report(d) -> str:    # 中文报告，第一行是标题，最后一行是结论
```

`pangu kernel` 按 `KERNELS` 表逐个 `importlib.import_module` + `demo()`，任何一项 `ok=False` 即退出码 1。

| 模块 | 判据 | 目标 | 1.1.5 实测 |
|---|---|---|---|
| `pde.py` | 一维热传导 L∞（对解析解） | < 1e-2 | 1e-6 |
| | 平流收敛阶（一阶迎风应 ≈1） | 0.8–1.2 | 0.827 |
| | 浅水能量漂移 | < 2% | 0.006% |
| `atmos.py` | 全球均温 | 12–17 ℃ | 14.68 |
| | 极地放大（S+2%） | 2–3 | 2.18 |
| | 雪球阈值（Budyko ~2%） | ≥ 0.93 | 0.98 |
| `radiation.py` | 地球温室 | 33 ± 3 K | 32.04 |
| | CO₂ 翻倍 | 2.0–4.0 K | 2.49 |
| `geo.py` | 临界瑞利数 | 657.5（误差 <1%） | 657.5 |
| | 板块速度 | 1–10 cm/yr | 1.72 |
| | 地幔热流 | 60–90 mW/m² | 61.8 |
| `orbit.py` | 辛积分能量漂移 | < 1e-6 | 8.7e-11 |
| | 水星近日点进动 | 43 ± 1 ″/cy | 43.0 |
| | 潮汐去旋 | 1.8 ± 0.6 ms/cy | 2.06 |
| `chem.py` | 4×CO₂ 回落时标 | 1e5–5e6 yr | 1.32e5 |
| | 暗淡年轻太阳 | CO₂ 涨 >4× 且 ΔT > 3 K | 420→4547 ppm，+6.3 K |
| `life.py` | 物种-面积指数 z | 0.15–0.40 | 0.247 |
| | 营养级传递 | 10%/级 | 10% |
| `units.py` | 硬域拦截 | 10/10 按预期 | 10/10 |

### 2.1 两处被逼出来的真错（已修在源码里）

1. **`chem.T0` 与辐射层不自洽**：写死 288 K，而 `radiation.solve(420)` 给 286.07 K。恒温器的平衡态因此偏离参考态，`relax` 停在 470 ppm。改为 `T0 = radiation.solve(CO2_0)["t_surface_k"]`。
2. **太阳常数被乘进风化项**：`w *= solar_rel` 等于「太阳暗了石头风化更快」。风化只经温度间接看太阳。删除后平衡回到 420 ppm / 286.1 K。

### 2.2 两处模型天花板（写进口径，不修）

1. **灰体温室上限**：单波段 `TAU_MAX = 1.6`，温室最多约 `T_e` 的 20%。−30% 太阳下纯 CO₂ 只能从 247 K 抬到 253 K，剩下 33 K 必须靠 CH₄ 与低反照率（未建模）。判据因此写成「CO₂ 涨 >4× 且 ΔT > 3 K」，不是「回到 288 K」。
2. **z 不是常数**：同一中性模型换取样窗口，z 从 0.17（16×）走到 0.32（1024×）。报告里把窗口与 z 并列打出来。格子模型（相关长度数格）量出 0.7，不是 bug，是尺度。

## 3. 守恒账本（`conservation.py`）

```python
ledger(world) -> {
  "rows": [ {id, book, name, inflow, outflow, residual, unit, tol, ok, status, note} ],
  "scored": int, "info": int, "skipped": int,
  "bad": [id], "explained": [id], "unexplained": [id],
  "ok": bool,
}
```

- **status**：`ok` / `warn` / `info`（储库，只报不判）/ `skip`（缺字段）。
- **residual** 是相对值 `(inflow − outflow) / |inflow|`。
- **explained**：不平衡由「声明值压过模型」造成（目前只有 C02）。按 1.1.4 的口径，这是提示不是错误——`validate` 的 C01 与 `review` 的 D10 据此判 `pass`，账本照常显示残差。

| ID | 账 | 公式 | 容差 |
|---|---|---|---|
| C01 | 能量 | 吸收 `S(1−α)/4` vs 出射 `σT_s⁴/(1+τ)` | ±1% |
| C02 | 能量 | 声明均温 vs 辐射解 | ±5% |
| C03 | 水 | 库存 km³ vs `4πR²·f_ocean·h` | ±5% |
| C05 | 碳 | 大气柱 `4πR²P/g`（储库） | 只报不算 |
| C06 | 碳 | `m_air·x_CO₂·44/28.97`（储库） | 只报不算 |
| C08.x | 元素 | `chemistry.composition.{planet,atmosphere,ocean}` 合计 = 1 | 1e-6 |

**建账第一天抓到的矛盾**：赫利孔声明 33 K 温室，但 10% CO₂、118 kPa 按辐射解给 51.5 K，均温 287.8 vs 306.4（差 18.6 K）。账本摆出来，不替作者改。

## 4. 误差传播（`uq.py`）

一阶线性、按独立处理：

```
σ_out = sqrt( Σ_i (∂f/∂x_i · σ_i)² )
```

输入区间（`DEFAULT_RANGES`，世界可用 `meta.uncertainty` 覆盖）：

| 输入 | 区间 | 类型 |
|---|---|---|
| 反照率 | ±0.05 | 绝对 |
| 光度 | ±1% | 相对 |
| 半径 / 质量 | ±1% | 相对 |
| 气压 | ±2% | 相对 |
| CO₂ | ±20% | 相对 |
| 倾角 | ±0.5° | 绝对 |

输出 U01–U05：平衡温度、地表温度、重力、逃逸速度、密度，各带 `pm`、`rel` 与主要来源（前三项）。

**口径**：这是**敏感度**，不是置信区间。强非线性处（雪球分岔、失控温室）会低估；相关项按独立处理是**乐观**估计。地球实测：`254.3 ± 4.6 K`（反照率主导）。

## 5. 适用域声明（`certify.py`）

把关键结论分四类：

| 类别 | 含义 | 例 |
|---|---|---|
| `computed` | 从别的字段推出来，可复算、可带 ± | 重力、逃逸速度、平衡温度、宜居带、NPP 折算人口 |
| `mixed` | 算一半、填一半 | 地表温度 = 平衡温度（算）+ 声明温室（拍） |
| `empirical` | 有模型但是拟合的 | 纬向温度场、降水场、群系、Miami NPP |
| `declared` | 作者写的设定值 | 反照率、倾角、声明温室、光度 |

`coverage = computed / total`。赫利孔：16 条，算 8 / 半算 1 / 经验 3 / 声明 4 → **50%**。

`certify --write` 落到 `world["certification"]`：`coverage / total / computed / mixed / empirical / declared / claims[] / not_modeled[] / generator`。

**不要**把 `mixed` 当 `computed` 用——地表温度的数字一半来自作者。

## 8. 校验与体检

### 8.1 `validate` 新增（维度「定量」，39 → 44 条）

- **C01** 守恒账本配平：无账可算 → skip；全平 → pass；只有 `explained` 不平 → pass（附说明）；有未解释的不平 → warn。
- **C02** 量纲硬域：扫 `bodies[0]` 与 `atmosphere` 的数值字段，`units.check` 报 hard → warn。
- **C03** 适用域：无 `certification` → skip；覆盖率 <30% → warn。

### 8.2 `review` 新增（九项 → 十一项）

- **D10 守恒**（软）：账本不平且无法用「声明压过模型」解释时提示。
- **D11 适用域**（软）：覆盖率与四类计数；`--fast` 跳过。

## 10. 已知缺口（不写进营销的那部分）

1. **没有三维环流**：`atmos` 是一维能量平衡；`pde` 只到一维线性浅水。
2. **板块是快照**：有速度与热流的标度律，没有时间演化。
3. **没有生物地球化学**：碳循环只有一个回路，无碱度、无 N/P/Fe 限制。
4. **没有文明层**：人口上限是热量折算，不是决策模型。
5. **没有全耦合**：八个内核各自对表，未用统一时间步拧成一台机器。
6. **误差表覆盖的是关键结论**（约 16 条/世界），不是每一个数字。

下一版该做的，按性价比排序：**大气环流（降水从「合理」到「正确」）→ 全局误差表 → 板块时间演化**。

## 11. 预览页：账本视图（`preview` 的 1.1.5 部分）

命令行能看的，页面上也必须有——否则「算了但没人看见」等于没算。

### 11.1 数据契约

`cmd_preview` 在生成时算好一份 `books` 载荷，塞进 `<script id="pangu-books" type="application/json">`：

```jsonc
{
  "version": "1.1.5",
  "fast": false,
  "kernel":  {"rows": [{module, label, since, ok, report}], "passed": 8, "total": 8, "ok": true},
  "ledger":  {"rows": [...], "scored": 5, "info": 2, "skipped": 1,
              "bad": ["C02"], "explained": ["C02"], "unexplained": [], "ok": false},
  "uq":      {"rows": [{id, name, value, pm, unit, rel, drivers[]}], "ranges": {...}, "note": "..."},
  "certify": {"coverage": 0.5, "total": 16, "by_kind": {...}, "rows": [...],
              "deviations": [{target, curve, reference, model, unit, ok}], "domains": {...}},
  "units":   {"rows": [{path, value, want, got, ok, msg}], "bad": 0, "ok": true},
  "replay":  {"rows": [{layer, status, seed, stored, got, note}], "verified": false, "ok": true},
  "checks":  [{id, question, verdict, note, level}]
}
```

每一段都独立 `try`：某段算不出来只让那张卡片空着，**不能让 3D 预览整页打不开**。

### 11.2 八张卡片

| 卡片 | 画什么 | 数据源 |
|---|---|---|
| 适用域 | 覆盖率环形图 + 四类堆叠条 + 「不是算出来的」清单 | `certify` |
| 误差 | `值 ±` 表 + 相对误差条，悬停看主导项 | `uq` |
| 守恒账本 | 逐行残差条，**竖线 = 容差**；`explained` 单独标注 | `ledger` |
| 物理内核 | 八个格子，点开看完整自检报告（等宽字体） | `kernel` |
| 可复算 | seed / 存档 hash / 重放 hash 三列 | `replay` |
| 量纲硬域 | 哪个数会被拒、判定是 hard/soft/ok | `units` |
| 定量体检 | C01–C03、D10–D11 的判定与说明 | `checks` |
| 基准对表 | 地球 25 条 + 火星 1 条，参考 vs 实测 | `certify.deviations` |

顶部五个徽章是这一页的摘要：`内核 8/8`、`账本 4/5 平`、`算出来 50%`、`hash 已记录`、`体检全绿`。

### 11.3 性能与降级

| 模式 | 耗时 | 内容 |
|---|---|---|
| 默认 | ≈ 6 s | 内核自检（2.4 s）+ 地球基准（2.8 s）+ 账本/误差/适用域（0.1 s）+ 读存档 hash |
| `--fast` | ≈ 0.3 s | 跳过内核与基准，只留账本/误差/适用域/火星那一条 |
| `--replay` | ≈ 2 min | 额外真重放 map（90 s）与 ca（40 s）对 hash |

**降级**：3D 加载失败时显示数据页，页面顶部按钮组里仍有「账本」——这一页是纯 DOM，不依赖 WebGL、不依赖 CDN。没有账本数据（旧产物）时，底部控制条的「账本」按钮自动隐藏，不给点了没反应的入口。

### 11.4 验收

`selftest` **V12**：`preview --fast` 生成的 HTML 必须含 `id="books-view"`、占位符 `__PANGU_BOOKS_JSON__` 已被替换、且注入的 JSON 里 `ledger` 非空。
