# 开发文档 · v1.1.7 问学层与艺术层

1.1.6 把「时间」补上了（`chronicle`），也给了名字的骨（`naming`）。这一版补同一件事的另一半：
**他们会提出什么假说，他们会做什么样的艺术。** 两层的共同约束只有一条——

> 不发明新物理。只把前面已经算出来的量（温度、压强、声速、重力、日长、天光、天象）
> 翻译成「人会怎么想、会做什么」，而且每条结论必须能指回具体字段。

## 1. 问学层（`inquiry`）

### 1.1 为什么是这一层

编年给出「发生了什么」，命名给出「叫什么」。还有一问没人回答：**他们想得明白什么，想不明白什么。**

这一层的唯一自变量是**观测能力**：

```
天光亮度 → 极限星等 → 肉眼可见星数 → 能测什么 → 假说的形状
重力 / 大气 / 化学 / 生化 → 造得出什么仪器 → 难题在哪里停住
```

### 1.2 四类划分（这一层存在的理由）

| 类 | 定义 | 判据 |
|---|---|---|
| `known` | 他们已经确定的事 | 有可重复的测量，误差小于结论本身 |
| `hypotheses` | 在自己信息集内**合理**的解释 | 能解释已见现象，但可能是错的（像托勒密） |
| `puzzles` | 提出的、当前技术解不开的 | 理论上可解，缺的是工具 |
| `unknowable` | **物理上拿不到信息**的 | 不是难，是这条路被封死了 |

`unknowable` 是价值所在：把「还没研究出来」和「永远不可能知道」分开，一个世界才有边界，
而不是一个可以无限往里填的袋子。

### 1.3 规则与数据契约

21 条规则（K01–K03 / H01–H09 / P01–P04 / U01–U05），强度只有两档：`必然`（可由数值算出）与
`很可能`（信息集内的合理外推）。每条带 `src`，由 `ws.resolve_path` 过滤；全失效时退回 `meta.name`。

```json
"inquiry": {
  "generator": "inquiry/1.1.7",
  "seed": 7,
  "hash": "6eb3be4d",
  "groups": {
    "known":      [{"id": "K01", "kind": "known", "title": "历法", "text": "……",
                    "strength": "必然", "src": ["cosmology.calendar"]}],
    "hypotheses": [], "puzzles": [], "unknowable": []
  },
  "summary": {"n_known": 3, "n_hypotheses": 9, "n_puzzles": 4, "n_unknowable": 4,
              "limit_mag": 3.94, "naked_eye_stars": 219}
}
```

### 1.4 判定

`inquiry --check` 三件事：内容 hash 与存档对账、被手改检测、`src` 是否还能解析。

> 与 `chronicle` 不同，**这一层不掷骰子**：hash 只覆盖内容，换 seed 不变。
> 改物理量才变 —— 变的不是文风，是可观测的信息集。

### 1.5 验收

| 编号 | 断言 |
|---|---|
| V28 | 四类齐全，每条带可溯 `src` 与强度 |
| V29 | 换 seed 结果不变（确定性） |
| V30 | `--write` 后 `--check` 绿；手改一条结论后退出码 1 |

### 1.6 示例（赫利孔）

已知 3、假说 9、难题 4、不可知 4。四条不可知：视差不成立（背后没有更暗的背景）、银河不可见、
系外行星无法确认、恒星内部不可达。理由都是一句话：**星表只有 219 个样本，而且全是亮的，
任何统计都会得出「星只有一种」。** 星夜（单星、极限星等 6.5）只留两条。

## 2. 艺术层（`aesthetic`）

### 2.1 立场

艺术是「感官在特定物理条件下的最优解」，不是随手的审美。三件事，前两件真算、第三件外推。

### 2.2 两件真算的事

- **声速** `c = sqrt(γRT/M)`，`γ = 1.4`。同一根管子，基频偏移 `12·log2(c/343)` 个半音。
  赫利孔 339.9 m/s → 低 0.2 个半音：差不到半个半音，耳朵分辨不出，但**它是可算的**，
  偏移来自平均温度与摩尔质量。
- **光谱峰值** 维恩位移 `λ = 2.898e6 / T`。赫利孔三星平均 649 nm，环境光偏红，蓝颜料得靠矿物硬磨。

重力取派生表 `gravity_g_calc`（与 `validate` / `entail` 同一处），不读声明值。

### 2.3 一条外推的事

调色板（V01）/ 影的画法（V02，≥2 光源才出）/ 暗部（V03）/ 音高（M01）/ 节奏（M02）/
乐器（M03，体型 ∝ `g^-0.33`）/ 建筑（A01）/ 城市形态（A02）/ 文学（L01）/ 叙事（L02）/
仪式（R01）/ 一件可演出的作品（W01）。这些标 `很可能`。

条件性输出是硬规矩：**不适用的规则返回 `None`**，不给与物理量矛盾的结论。
零重力世界不出乐器与建筑，单星世界不出「两道影的画法」，24 小时日长不出「节奏」。

### 2.4 数据契约

```json
"aesthetic": {
  "generator": "aesthetic/1.1.7",
  "seed": 7,
  "hash": "a2b1719f",
  "senses": {"sound_speed": 339.9, "sound_ratio": 0.991, "lambda_nm": 649,
             "gravity_g": 1.76, "day_hours": 31.4, "n_sun": 3, "n_moon": 1,
             "ocean": 0.773, "tilt": 18.2, "tidal_locked": false},
  "forms": [
    {"id": "M01", "kind": "music", "title": "音高", "text": "……",
     "strength": "必然",
     "src": ["atmosphere", "cosmology.bodies[0].planet_map.summary.mean_temperature_k"]}
  ],
  "summary": {"n_forms": 11, "sound_speed": 339.9, "peak_nm": 649, "day_hours": 31.4}
}
```

### 2.5 判定与验收

`aesthetic --check` 与问学同构：hash 对账 + 手改检测 + `src` 失效。
**改了世界没重跑 `--write`，`--check` 与 `review` D15 会点名。**

| 编号 | 断言 |
|---|---|
| V31 | 声速对 `sqrt(γRT/M)` 复算一致（<1%），重力非零 |
| V32 | 每条形式都挂 `src`，至少 5 条 |
| V33 | `--write` 后绿；把倾角改成 80° 后红 |
| V34 | `--kind` 过滤只返回该类 |
| V35 | `--md` 两层都能落成 Markdown |

### 2.6 开发中踩的坑（写在这里，不写进营销）

重力最初读 `surface_gravity_g` —— 一个不存在的键。于是整个世界重力都是 0，
乐器与建筑两类规则连带失效，报告上却只写着「重力 0.00 g」。
改读 `gravity_g_calc` 之后，V31 直接对 `sqrt(γRT/M)` 复算：**字段名不能凭记忆，体检要能自己验算。**

同一批修掉的还有：多光源世界写死「两道影」；音高写成「高 −0.2 个半音」；日长短于 24 h 时输出
「长 −20%」；0.02 天（29 分钟）的余数被说成「一种特权」；引用作者原文时套了两层引号。

## 4. 已知边界

- 问学只推「能测到什么」，不推「会发明什么技术」——后者取决于偶然与个例，不可复算。
- 艺术不给好坏，只给「这个感官条件下最优解的形状」；审美判断仍归作者。
- 两层都不掷骰子：想让它们「换一种说法」，改的是世界，不是 seed。
