## 0. 一页纸

| 项 | 内容 |
|---|---|
| 主题 | **从「像」到「准」，再从「准」到「算」** |
| 一句话 | 1.1.4 能说「这个世界长这样，我知道它离地球差多少」；2.0 才敢说「这个世界的天气是解出来的，不是画的」 |
| 版本数 | **11 个**：1.1.5 → 1.2 → … → 1.10，再加 2.0 收口 |
| 1.1.5 做什么 | 守恒审计 + 二十条基准曲线 + 单位/量纲系统 + 误差传播。**不加新物理，先把「错多少」变成可读的数字** |
| 总工期 | 1.1.5：2–3 周；全路线：约 **70–110 人月**（3–5 年，2–4 人） |
| 硬约束 | 每一版都**只能加基准曲线，不许删**；旧 `world.json` 永远能打开 |
| 不可达 | 全球量子态、10⁴⁴ 分子的分子动力学、混沌系统的长期逐点预报——**永远做不到，方案里明写** |

**先说结论**：盘古与「真实世界」的差距不是一个数量级，是**五个层级**。而「真实世界」本身在数学上就不可完全仿真（§5）。所以这份方案的目标不是「变成真实世界」，是**变成一个可证伪的近似序列**——每一层都写清适用域、截断尺度与误差，并且能被对表推翻。

## 1. 判据：什么叫「真实世界模型」

### 1.1 五个保真层级

| 层 | 名字 | 是什么 | 盘古 1.1.4 在哪 |
|---|---|---|---|
| **L0** | 描述层 | 参数 + 文本：「重力 1.76 g」「两颗太阳」 | 大部分在这里 |
| **L1** | 守恒层 | 质量/能量/动量**闭合**，账算得平 | 局部有（P01 四数自洽、sky 的星等），全局没有 |
| **L2** | 连续介质层 | 偏微分方程求解：流体、热传导、弹性、扩散 | **完全没有**（现有场是经验式插值） |
| **L3** | 微观层 | 原子/分子：MD、DFT、反应速率 | 只有「成分比例」这一层符号 |
| **L4** | 量子层 | 波函数、量子场、标准模型 | 只有常数（G、α 是手填的） |
| **L5** | 宇宙学 | 时空度规、结构形成 | 只有「框架标签」 |

> 一条容易被误解的事：**L4 不是「最高级」，L4 是「最底层」**。真实世界不是从量子往上「搭」出来的——是每一层都有自己的有效理论，量子的作用在绝大多数尺度上被**打包成常数与速率**交给上层。§3.1 会给出这条链的具体例子。

### 1.2 「准」的三条判据

1. **可对表**：给定已知输入（地球、火星、金星），输出的关键曲线落在已知区间内，且**误差是写出来的数**，不是「大致合理」。
2. **可闭合**：能量、质量、动量、元素守恒有账本；每一版的收支必须配平到声明精度。
3. **可推翻**：存在一条实验/观测，做出来能证明模型错了。做不到这一条，它就不是模型。

### 1.3 现状坐标（1.1.4 的自评）

| 维度 | 现状 | 差 |
|---|---|---|
| 温度 | 纬向余弦 + 高度 + 海陆 | 不是辐射平衡解，没有日变化、没有云、没有平流层 |
| 降水 | 水汽输送 + 地形抬升 + 下沉支抑制 | 没有原始方程，没有季风，没有风暴路径 |
| 地形 | 静态 Voronoi 板块 + 噪声 | 没有时间演化，没有均衡回弹，没有侵蚀 |
| 演化 | 元胞自动机（扩散 + 适应度） | 没有遗传、没有物种、没有食物网 |
| 星表 | 程序生成、可复算 | 不接真实星表（设定选择，非缺陷） |
| 基准 | 6 条曲线 | 目标 60+ 条，覆盖流体、地质、化学、生态 |
| 计算 | 140k 格、纯 Python、秒级 | 目标 10⁸ 格、PDE 内核、分钟级 |

**一句话**：1.1.4 站在 L0 与 L1 之间，靠**经验闭合**把 L2 的方程绕过去了。这条捷径在「造一个自洽的架空世界」上是对的，在「模拟真实世界」上是错的。

## 2. 差距总表（按物理分支）

打分是「距离可证伪的定量模型」：○ 有模型能对表 ｜ △ 有符号无方程 ｜ ✕ 完全没有。

| 分支 | 关键内容 | 盘古现状 | 真实世界 | 差在哪 |
|---|---|---|---|---|
| **量子力学** | 谱线、跃迁、隧穿、退相干 | ✕ 只有常数 | 一切化学与光学的底座 | 不需要全球波函数，需要「谱线表 + 反应速率」 |
| **原子分子** | 电子结构、键能、相图 | △ 成分比例 | DFT/MD 可算 | 缺「矿物相」与「材料」这一层 |
| **热力学** | 状态方程、相变、熵产生 | △ 单点温度 | 局地平衡 + 输运 | 没有 EOS，没有潜热，没有相变耦合 |
| **流体力学** | Navier–Stokes、湍流闭合 | ✕ 解析风带 | DNS/LES/RANS | **最大的一块空白** |
| **辐射传输** | 多波段吸收、散射、温室 | ✕ 经验 ΔT | 逐层求解 | 温室是手填常数 |
| **固体地球** | 地幔对流、板块动力学、流变 | ✕ 静态快照 | Stokes + 流变律 | 地形有「形」无「史」 |
| **轨道力学** | N 体、共振、潮汐耗散 | △ 圆轨道 + 开普勒 | 辛积分 + 摄动 | 没有长期演化，没有混沌判据 |
| **恒星物理** | 结构、演化、星风 | △ 光度常数 | MESA 级 | 只有寿命一阶估算 |
| **化学** | 反应网络、光化学、生物地球化学 | ✕ | 数百物种的 ODE | 完全没有 |
| **生命** | 遗传、代谢、种群、演化 | △ CA 抽象 | 谱系 + 动力学 | 不可解释：能跑，但说不出为什么 |
| **认知/文明** | 决策、技术、聚落 | ✕ 只有叙事 | 多主体模型 | 世界造到「人」就停了 |
| **计算/工程** | 单位、UQ、并行、复算 | △ hash + 部分复算 | 全链路可复算 | 无量纲系统，无误差传播 |

## 3. 量子物理该放在哪（用户点名的那一条）

### 3.1 量子在造世引擎里的正确位置：**给上层提供常数与速率**，不是模拟全球波函数

一条真实的因果链，从 α 到一个世界的夜空：

```
精细结构常数 α
  → 原子能级（Rydberg 1/α²）
    → 谱线位置（H、He、Na、O₂、CO₂、H₂O 的吸收带）
      → 大气不透明度（k-distribution）
        → 温室效率（ΔT）
          → 地表温度
            → 液态水存在与否
              → 生命
```

盘古现在把这条链**截断在第二格之后**：温度用一个 `greenhouse_delta_k` 常数，谱线一条也没有。1.4 版要把这条链接上——**接法不是解薛定谔方程，是引入一张谱线表 + 一个 k-distribution 求解器**。

### 3.2 量子必须进入模型的四个地方（以及为什么只需要这四个）

| 位置 | 为什么非得是量子 | 引擎要什么 | 版本 |
|---|---|---|---|
| 光谱与不透明度 | 吸收带的位置由能级决定，经典电磁学给不出 | 谱线表（HITRAN 量级，可裁剪） | 1.4 |
| 化学反应速率 | Arrhenius 的指前因子与活化能来自过渡态 | 速率常数表 / 简化机理 | 1.4–1.7 |
| 放射性衰变 | 隧穿，经典概率为零 | 半衰期表 + 生热项 | 1.5 |
| 材料电子性质 | 带隙决定「能不能做半导体」 | 材料属性表（若文明层要用电） | 1.9 |

### 3.3 量子**不该**进入的地方（写死，防止跑偏）

| 想法 | 为什么不做 |
|---|---|
| 全球波函数 | 10⁴⁴ 个自由度；退相干时间 ~10⁻²⁰ s，宏观上早已经典 |
| 从头算（ab initio）整颗行星 | 1 m³ 空气 = 2.5×10²⁵ 个分子，单步就要 10²⁸ flops |
| 量子随机数当「真随机」 | 引擎需要的是**可复算**的伪随机；量子测量不可克隆，正好毁掉复算 |
| 用 QFT 推常数 | α、G、mₑ 是**输入**，不是输出。宇宙学层面的参数选择不在造世工具的范围 |

> **一句总结**：量子力学在盘古里的地位，等于「编译器」——上层写世界，下层提供精确到 10⁻⁶ 的常数与速率表；没有人会用汇编去写小说。

## 4. 十一个版本的路线

**读法**：每格给「主题 / 一句话 / 新增 / 判据（怎么算做完）/ 成本 / 为什么不能跳过」。
**不变的规矩**：`benchmark` 的曲线数**只增不减**；每版结束必须让旧 `world.json` 仍能打开（迁移脚本 + 兼容层）。

---

### 1.1.5 · 守恒与误差（Conservation & Uncertainty）

> **一句话**：不加新物理，先把「我错多少」变成一张能读的表。

- **新增**
  - `benchmark` 从 6 条扩到 **20 条**：加入地球的大气质量、海洋热含量、极地放大系数、ITCZ 位置、季风爆发日、河流年径流、侵蚀速率量级、地热流、磁场强度、昼长季节性……
  - **守恒账本** `conservation.ledger`：入射辐照 − 反射 − 出射长波 = 0（±1%）；降水 = 蒸发（±5%）；侵蚀 = 沉积（±10%）。不配平就 `review` 红。
  - **单位与量纲系统**：`_km` / `_au` 这种命名约定退役，改成带量纲的类型；`patch` 写入 10⁹ K 时直接拒绝。
  - **误差传播**：每个派生量带 `±`，来自输入区间（`albedo 0.3±0.05` → `T_eq ±4 K`）。
- **判据**：20 条曲线全过；账本配平；随机数全链路可复算（`--replay` 从 seed 重放任意一步）。
- **成本**：2–3 周 ｜ **不可跳过**：没有账本与量纲，后面每一层都会「算出漂亮的错数」。

---

### 1.2 · 连续介质内核（PDE Core）

> **一句话**：把「经验式」换成「解方程」，但先只解最简单的那些。

- **新增**：有限体积框架（结构网格 → 四叉/八叉自适应）、显式/隐式时间推进、热传导方程、扩散-平流方程、浅水方程；把温度场从余弦插值换成**能量平衡 + 扩散**。
- **判据**：一维热传导对解析解（误差 < 1%）；二维浅水对 Williamson 标准测试集 Case 1/2（L2 误差 < 5%）；地球年均温度 RMSE **< 4 K**（现在是 6.7）。
- **成本**：2–3 人月 ｜ **不可跳过**：这是后面所有流体的地基。

---

### 1.3 · 环流（Atmosphere & Ocean Dynamics）

> **一句话**：让风和水真的流起来，季节才会「动」。

- **新增**：三维原始方程（静力近似）大气、Boussinesq 海洋、海冰热力学、昼夜与季节强迫、边界层参数化。
- **判据**：纬向风急流位置 ±5°；Hadley 环流边界 ±5°；地球海温 RMSE < 3 K；季风爆发日 ±15 天。
- **成本**：6–9 人月 ｜ **不可跳过**：没有环流，降水永远是「合理」而不是「正确」；文明的农业也永远算不准。

---

### 1.4 · 辐射与光化学（Radiation & Photochemistry）

> **一句话**：把 §3.1 那条链接上——谱线 → 不透明度 → 温室。

- **新增**：多波段辐射传输（k-distribution，16–32 band）、HITRAN 裁剪谱线表、云微物理（双参数 bulk）、光化学网络（O₃/NOₓ/CH₄，50–150 物种）、温室由分压**算出来**而不是填。
- **判据**：地球 33 K 温室自动复现（±3 K）；CO₂ 翻倍 +3.0 K（±0.5）；臭氧层高度与柱量 ±20%；火星 −60 K 反照率-温室对表。
- **成本**：6–10 人月 ｜ **不可跳过**：这是「量子进入模型」的唯一正门；也是「换一颗恒星，温室怎么变」的唯一算法。

---

### 1.5 · 固体地球（Geodynamics）

> **一句话**：让地图有「历史」，而不是一张贴图。

- **新增**：地幔对流（Stokes，温度相关黏度）、板块运动**动力学**（不是 Voronoi）、岩石圈流变、地形演化（抬升-侵蚀-沉积-均衡）、放射性生热、低阶地磁发电机。
- **判据**：板块速度分布 1–10 cm/yr；山脉高度-侵蚀平衡（±20%）；地热流 60–90 mW/m²；大陆漂移 1 亿年后可复算且形态合理。
- **成本**：8–12 人月 ｜ **不可跳过**：地形是所有生态与文明的底；没有「史」的地图，写不出「这块盆地为什么是粮仓」。

---

### 1.6 · 轨道与恒星（Orbital & Stellar Evolution）

> **一句话**：把「某一天」变成一个可以前后翻的 10 亿年。

- **新增**：N 体辛积分（含潮汐耗散、自转演化、岁差）、长期混沌判据（Lyapunov 时间）、简化恒星演化（主序 → 红巨星）、行星形成粗模型（星子吸积）。
- **判据**：太阳系 1 亿年轨道演化与 Laskar 解一致（半长轴漂移 < 1%）；地球日长每世纪 +1.8 ms；宜居带随光度外移速率对表。
- **成本**：4–6 人月 ｜ **不可跳过**：「他们还有多久」是世界观里最贵的一句话。

---

### 1.7 · 物质与化学（Materials & Chemistry）

> **一句话**：从「元素比例」走到「矿物、岩石、反应」。

- **新增**：热力学数据库（CALPHAD 简化）、矿物相平衡、反应-输运耦合、生物地球化学循环（C/N/P/Fe/S）、成矿与土壤形成。
- **判据**：地球地壳矿物丰度前 10 排序正确；海水 pH 与碱度 ±0.2；土壤碳储量 ±40%；一次大氧化事件的定性复现。
- **成本**：8–12 人月 ｜ **不可跳过**：文明的技术树是长在矿物上的——没有矿物，就没有「青铜时代」。

---

### 1.8 · 生命的动力学（Life as Dynamics）

> **一句话**：把 CA 换成「代谢 + 遗传 + 种群」的三件套。

- **新增**：个体基模型（agent-based，10⁶–10⁷ 个体）、基因组符号串与突变、代谢网络（通量平衡分析）、食物网动力学（Lotka–Volterra 多元）、物种形成与灭绝曲线。
- **判据**：地球式物种-面积关系（z ≈ 0.25）复现；背景灭绝率 0.1–1 /百万种年；营养级能量传递效率 8–12%；一次大灭绝后恢复时间 5–10 Myr。
- **成本**：10–15 人月 ｜ **不可跳过**：现在的 CA「会动但不可解释」，而设定最需要的恰恰是解释。

---

### 1.9 · 认知与文明（Cognition & Civilization）

> **一句话**：世界第一次长出「人」，而不只是「叙事文本里提到人」。

- **新增**：感知-决策模型（有限理性）、能量与技术动力学（人均 W、技术树状态机）、聚落选址与贸易网络、人口-资源耦合、历史时间轴 `world.timeline`。
- **判据**：地球人口曲线 1 万年误差 < 30%；城市化率-人均能量关系定性正确；一次技术跃迁的触发条件可复算。
- **成本**：10–15 人月 ｜ **不可跳过**：这是「架空世界」与「世界模型」的分水岭。

---

### 1.10 · 耦合与性能（Coupling & Performance）

> **一句话**：把九个模块拧成一台机器，而不是九个互不相干的脚本。

- **新增**：统一时间步与算子分裂、跨模块数据总线（气候→地质→生态→文明）、集合预报（20–50 成员）、自适应网格、C/Rust 内核 + Python 编排、增量复算（改一个参数只重跑受影响的下游）。
- **判据**：全耦合跑 1000 年不漂移（能量账本仍配平 ±1%）；单次全量 < 10 分钟（10⁷ 格）；改一个参数的下游重算 < 30 秒。
- **成本**：10–15 人月 ｜ **不可跳过**：不耦合的模块，误差会互相甩锅；不重构的性能，撑不起 1.3–1.9 的分辨率。

---

### 2.0 · 可证伪的交付（Falsifiable Delivery）

> **一句话**：把「我知道我错多少」变成产品——每份世界档案自动附一张误差表。

- **新增**：`pangu certify <world>` —— 输出该世界的**适用域声明**：哪些结论是算出来的（带 ±），哪些是经验式，哪些是拍的（标红）；与地球/火星/金星三组基准的偏差表；不确定性传播到最终叙事（「这个世界的农业上限是 3.2±1.1 亿人」）。
- **判据**：随机抽三个自造世界，第三方按声明复算，结果一致；误差表覆盖 100% 的定量结论。
- **成本**：4–6 人月 ｜ **不可跳过**：没有这一版，前面十版全是「更复杂的黑箱」。

## 5. 三条不可逾越的极限（写进方案，不写进营销）

### 5.1 混沌：逐点预报有硬上限

天气的 Lyapunov 时间约 **1–2 周**；行星轨道的约 **1000 万年**。这意味着：

- 「这个世界的第 3 年 4 月 12 日下不下雨」——**永远算不准，且不可能算准**。
- 能算准的是**统计量**：气候态、方差、极端事件频率。
- 所以 1.3 版的目标不是「预报」，是「复现统计」；`benchmark` 比的也必须是统计量。

### 5.2 量子测量：不可克隆，因此不可复算

引擎的全部可信度建立在「同 seed → 同结果」（1.1.4 已经做到星表/地图/演化的 hash 复算）。量子测量**本质上不可克隆**，用它做随机源等于自毁复算。所以：量子只作为**常数与速率表**进入，绝不作为随机源。

### 5.3 计算不可约（Computational Irreducibility）

很多系统的未来状态**没有比「跑一遍」更快的算法**。这意味着：

- 想要「精确」，就只能真算；想要「快」，就只能近似。
- 1.10 的「增量复算」是工程妥协，不是数学捷径。
- 任何声称「不用算就知道」的模块，都必须是**有误差条的近似**，且要能被基准抓住。

> 这三条不是免责声明，是**设计约束**：它们决定了每一版的判据必须是「统计量 + 误差条」，而不是「逐点正确」。

## 6. 架构改造（不写代码，先写契约）

| 现在 | 1.10 时 | 为什么必须改 |
|---|---|---|
| `world.json` 一个 dict | schema + 版本迁移 + 二进制场文件 | 10⁷ 格的场塞不进 JSON |
| 单位靠字段名后缀 | 量纲类型系统 | 10⁹ K 这类错误必须编译期死 |
| 纯 Python | C/Rust 内核 + Python 编排 | 性能差 100–1000× |
| 每模块各自复算 | 统一时间步 + 数据总线 + 增量重算 | 耦合后误差互相甩锅 |
| hash 只覆盖三处 | 全链路可重放（`--replay`） | 「可证伪」的前提是「可复现」 |

**兼容策略**：`world.json` 的每个字段带 `since: 1.x`；读取时按版本升迁；写入永远写最新版。**旧世界永远能打开**是硬约束，不是善意。

## 7. 验收：每一版怎么算「做完了」

三件套，缺一不算完：

1. **基准曲线**：新增曲线全过（或明确标注「未达标，偏差 X」，且写进档案）。
2. **守恒账本**：本版新增的物理过程必须入账，且配平到声明精度。
3. **可复算**：同 seed 重跑逐位一致；跨平台（Win/Linux）一致。

> 一条元规则：**基准曲线只增不减**。删曲线 = 承认退步，必须写在 CHANGELOG 的「已知退步」里。

## 8. 风险与「不要做什么」

| 风险 | 表现 | 对策 |
|---|---|---|
| 无限扩张 | 每一版都想「顺手加个模块」 | 每版只准动 1 个主模块 + 1 个基准扩容 |
| 精度幻觉 | 算出 6 位小数，误差 ±50% | 数值必须带 ±，且由 1.1.5 的 UQ 强制 |
| 性能悬崖 | 分辨率一升就崩 | 1.10 之前不许把默认分辨率提到 10⁷ 格 |
| 复杂度失控 | 没人能解释一个结果是怎么来的 | 每版必须留「一条从输入到输出的可读路径」 |
| 定位漂移 | 从「造世工具」变成「半成品气候模式」 | 见下 |

**永远不做**：

- 全球量子态模拟（§3.3）
- 全球 MD（10⁴⁴ 分子）
- 逐点长期天气预报（§5.1）
- 真实星表接入（设定选择，与 1.1.4 口径一致）
- 「精确模拟一个行星」这类表述（§9）

**盘古的定位不是「地球模拟器」**，是**「可以造一个世界，并且知道这个世界哪些数是算出来的、哪些是拍的」**。这条定位在十一个版本里都不许变——变了，它就既不如 GCM，也不如小说。

## 9. 对外表述

- 可以说：「盘古的每个数字都有误差条；`pangu certify` 会告诉你哪些是算的、哪些是估的。」

## 附录 B · 如果只能做三件（务实版）

如果十年太长，只做三件也值得：

1. **1.1.5 的守恒账本 + 量纲**——让所有数字第一次「算得平」。
2. **1.3 的大气环流**——降水从「合理」变「正确」，世界观的可信度立刻上一个台阶。
3. **2.0 的 `certify`**——把「我知道我错多少」变成产品，比多算十个量更能建立信任。

其余七件，是「要不要变成一台真正的行星模型」的选择题，不是「能不能用」的选择题。
