# 盘古 1.1.1 · 行星地图与 CA 强化（开发文档）

> 1.1.0 让世界「跑起来」，1.1.1 补上它缺的那层：**地**。
> 本文记录 1.1.1 的范围、数据契约、算法、验收与已知限制。面向维护者与要接着改的人，不面向第一次用盘古的人（那份在 `SKILL.md`）。

---

## 1. 范围

1.1.1 只做两件事，但都要做到能被复算打假：

1. **行星地图模块**（`scripts/mapgen.py` + `pangu.py map`）：从 `world.json` 推演一颗行星的陆地、海洋、山脉、河流、气候与群系分布，输出 PNG、正射地球和单文件交互页。
2. **元胞自动机强化**（`scripts/ca_engine.py`）：逐规则邻居半径、cos(lat) 面积加权、地图耦合、逐格 `final_hash`、韧性指标。

不做：大气环流/洋流/冰盖动力学、板块时间回放、完整生物气候分类、城市/农业选址。这些写进「已知限制」，不假装有。

---

## 2. 设计约束（不能破的）

| 约束 | 含义 | 为什么 |
|---|---|---|
| **单一数据源** | 地图只读 `world.json`，产物是派生文件；`map --write` 只回写摘要 + 72×36 粗场 | 手改 PNG/HTML 会让文档、图、CA 三方漂移 |
| **零第三方包** | 只用标准库；PNG 走 `png_writer.py`（zlib+struct） | 别人 clone 下来就能跑，不用 pip / Pillow / numpy |
| **同 seed 可复算** | `map --check` 两次 build 的字段哈希必须一致；`ca --check` 连最终格子 crc32 都要一致 | 「数字是跑出来的」不是口号，要能被机器验 |
| **设定优先于引擎** | 群系名字/颜色/高程带来自 `bodies[0].biomes[]`；海平面来自水量；温度来自恒星与大气 | 地球不是模板，引擎不能内置一套地球群系 |
| **失败要响** | 地图/CA 缺字段、规则矛盾、粗场长度不对 → 编译/推演期报错，不静默兜底 | 静默兜底会把错误藏到成片里 |

## 3. 数据契约

### 3.1 `bodies[0].planet_map`（作者可写，`map --write` 只补结果）

```jsonc
{
  "seed": 7,
  "tidal_locked": false,              // 可选；null rotation_hours 也会判锁定
  "tectonics": {
    "plates": 12,                     // 缺省 6 + 2.2×R⊕，夹在 6–16
    "hotspots": 5,                    // 缺省 2 + R⊕，夹在 2–7
    "relief_km": 5.6                  // 缺省 8.8 / g^0.8，夹在 2.5–12
  },
  "hydrosphere": {
    "solvent": "水",
    "mean_depth_km": 3.36,            // 缺省 0.30 × 2 × relief_km
    "inventory_km3": 7.75e9           // 缺省 area × 0.50 × mean_depth
  },
  "climate": {
    "mean_precip_mm": 978.7,          // 缺省 900 × (P/101.3)^0.55
    "temp_optimum_k": 292,
    "temp_tolerance_k": 30
  },

  // ── 以下是 map --write 写回的派生结果，不要手填 ──
  "summary": { "ocean_fraction": 0.7729, "max_elevation_km": 5.6, ... },
  "checks": [{"id": "M01", "ok": true, "note": "..."}],
  "hash": "d544bcfd",
  "sea_level_km": 1.423,
  "inventory_km3": 7.75e9,
  "figures": ["map/map-elevation.png", ...],
  "coarse": {                          // 72×36，base36；CA 用
    "nx": 72, "ny": 36,
    "habitat": "…", "temperature": "…", "elevation": "…", "ocean": "0101…"
  }
}
```

`coarse` 是唯一允许进 `world.json` 的「大数组」，四串各 2592 字符，合计约 10 KB；整张 360×180 图不进 JSON。

### 3.2 `biology.evolution.grid`

| 字段 | 类型 | 说明 |
|---|---|---|
| `area_weighted` | bool | 1.1.1 新增。开启后密度按 cos(lat) 加权；只对 `lon-closed` 有意义 |

### 3.3 `biology.evolution.map_coupling`（1.1.1 新增）

```jsonc
"map_coupling": {
  "field": "habitat",          // habitat / temperature / elevation
  "initial_from_map": true,
  "initial_bias": 0.8,         // 0 = 不用地图，1 = 强偏置
  "growth_gain": 0.8,          // 0 = 不影响生长
  "rules": ["R1", "R3", "R10"] // 只耦合这些规则；不写则耦合所有产生产者/消费者的规则
}
```

- 初始分布：生产者/消费者权重 `(0.12 + 0.88h)^bias`，裸岩 `(1.05 - 0.85h)^bias`，其他态 `0.55 + 0.45h`。
- 生长：规则概率乘 `(0.10 + 0.90h)^map_gain`。
- `map_coupling` 开启但 `planet_map.coarse` 不存在 → 编译失败，不降级。

### 3.4 `biology.evolution.summary`（1.1.1 新增字段）

| 字段 | 说明 |
|---|---|
| `final_hash` | 最终网格逐格 crc32（8 位十六进制） |
| `max_drawdown` | 主状态从历史峰值到之后谷底的最大相对跌幅 |
| `resilience` | 跌 20% 后 80 步内回到原峰值 80% 的事件比例 |
| `area_weighted` / `map_coupled` | 本次运行是否启用 |

旧版 summary 没有这些字段时，`ca --check` 仍按六个旧指标对账；一旦写了 `final_hash`，就按逐格哈希验。

## 4. 地图算法

### 4.1 网格

等距圆柱，`lat = 90 - (y+0.5)·180/ny`，`lon = -180 + (x+0.5)·360/nx`。每格面积 `R²·Δlon·(sin lat₂ - sin lat₁)`，总面积为 `4πR²`。经度环绕，纬度夹紧。

### 4.2 板块

1. 在球面撒 `P` 个 Fibonacci 点（带抖动）作为板块种子。
2. 每格归到点积最大的种子（球面 Voronoi）。
3. 每块板有「大陆性」`c ∈ [0.08, 0.98]` 与切向运动矢量（东/北基随机方向 × 0.35–1.0 速度）。
4. 相邻异板格对：`approach = (v_B - v_A)·normalize(c_A - c_B)`。
   - `> 0.12`：汇聚，两侧隆起 `0.55 + 1.10·approach`；洋-洋汇聚再挖窄海沟。
   - `< -0.12`：张裂，窄裂谷 + 肩部微隆。
   - 其余：转换，弱隆起。
5. 隆起场做两轮盒式模糊（半径 `max(2, nx/48)`），让山脉成带而不是贴边一条线。
6. 热点：随机羽流 + 沿板块运动方向 3–6 个衰减高斯，形成火山链。

### 4.3 地形

```
base = 0.98·low + 0.78·(c_smooth - 0.55) + 0.44·mid + 0.20·ridged
       + 1.15·uplift + 0.95·rift + 0.50·plume
```

- `low/mid/ridged` 是球面 3D 值噪声 fBm；采样前先做域扭曲（±0.22 的 3 倍频噪声），让海岸线长出分形细节。
- `c_smooth` 是板块大陆性先按 `max(2, nx/48)` 模糊两轮的结果；不模糊的话大陆边缘是刀切的 Voronoi 边。
- 原始场按 0.5%/99.5% 分位拉伸到总起伏 `2.05 × relief_km`（陆地最高 + 海洋最深）。
- **等ostasy上限**：解出海平面后，若最高峰 > `relief_km`，把陆地高出海面的部分按比例压回。重力大的世界山矮，这条必须生效。

### 4.4 海平面（水量解）

给水体积 `V`，把格子按高程升序排，累加面积 `A` 与一阶矩 `I = Σh·dA`。对每个前缀，候选海平面 `h_s = (V + I)/A`；当 `h_s < h_k` 时，海平面落在该格之下，回退一格即为解。返回 `(h_s, 海洋面积占比)`。

这一步是「推演」和「手画」的分界线：改水量，海平面、海洋占比、海岸线、河流入口全都跟着变。

### 4.5 温度

- 年辐照：对每个纬度，按转轴倾角在 `δ ∈ [-ε, ε]` 上取 13 个赤纬，算日平均 `cosZ`（含极昼/极夜），再平均。
- 非锁定：`T = T_mean + (f/f̄ - 1)·62`。
- 潮汐锁定：以 `substellar` 经纬度为热极，`T = T_mean + 55·cosψ - 18`（昼侧）/ `T_mean - 52 + 14·cosψ`（夜侧）。
- 大气热输送：温度场盒式模糊半径 2。
- 海拔递减：`6.5·g^0.25 · elev · 0.55`；海洋按深度轻微降温。
- 保均值：把偏移的 65% 拉回 `t_surface`（来自 `world_schema.compute_derived`，含 `greenhouse_delta_k`）。

### 4.6 降水

- 风带：`|lat|<30` 信风（东风、向赤道），`30–60` 西风（向极），`>60` 极地东风；锁定世界改为从直射点向外的切向风。
- 蒸发：海洋 `(T-268)/30`，陆地蒸腾乘 0.38；归一化到平均 1。
- 水汽平流：14 次半拉格朗日迭代，上游双线性采样，步长 `1.9×风速`；`source = evap + 0.965·upwind`；`loss = source·(0.045 + 0.28·lift)`，单步最多丢 82%。
- 抬升：`lift = clamp((u·∂h/∂x + v·∂h/∂y)/p90, 0, 1)`，只算陆地迎风坡。
- 标定：最后按面积加权平均缩放到 `climate.mean_precip_mm`（缺省由气压推）。

### 4.7 河网

1. priority-flood：从所有海洋格以海平面为源，把陆地洼地填到溢出高度。
2. 每格找填洼后最低的 8 邻居作为流向；没有更低邻居的闭流盆地记为湖。
3. 按填洼高度降序累加 `discharge += precip·area·0.55`。
4. 陆地流量 97.2% 分位以上记为河流；湖泊不画成河。

### 4.8 群系与宜居度

- 展示高程 `v`：海洋 `sea_v·(1 - depth/max_depth)^0.75`，陆地 `sea_v + (1-sea_v)·(elev/max_elev)^0.82`。
- 群系：读 `biomes[]` 的高程带；湿度修正只在中段生效：`v_eff = v + wet - dry`，`wet = clamp((P-760)/1800, 0, 0.07)`，`dry = clamp((380-P)/900, 0, 0.09)`。
- 极冰：`T + 4·(micro-0.5) < 265.5`（海冰）/ `< 268.5`（陆冰），`micro` 是 24 倍频高频噪声，用来抖冰缘。
- 宜居度：`f(T)=exp(-((T-292)/30)^2)`；海洋乘 `exp(-depth/2.2)`；陆地乘 `min(1, P/650)` 与海拔衰减 `0.45+0.55·exp(-elev/4.5)`。

## 6. CA 强化细节

### 6.1 逐规则邻居半径（bug fix）

1.1.0 的 `run()` 用 `max(r.radius)` 建唯一邻居表，所有规则都在这张表上数邻居；半径 1 的规则会看到半径 2 的格子。1.1.1 按 `(radius, shape)` 分组建表，`cnt_cache` 按组缓存，规则只读自己的表。示例全为半径 1，所以数值不变；但这是正确性修复，不是优化。

### 6.2 面积加权

`grid.area_weighted=true` 时，行权重 `cos(lat)`（下限 0.02），归一化后参与密度统计。极区一行只占赤道一行的 `cos(88°)/cos(0°) ≈ 0.035`，不再和赤道同权。`energy_spent` 仍按每次转移计，不做面积积分（避免把「能量」变成看不懂的大数）。

### 6.3 地图耦合

见 §3.3。示例：`field=habitat`、`initial_bias=0.8`、`growth_gain=0.8`，耦合 `R1/R3/R10/R14/R15`（裸岩→生产者）。结果：锈苔稳态 0.344、周期 34 步、最大回撤 23.5%、韧性 100%。

把同一张宜居度图分别喂给「开耦合 / 关耦合」两局，按 10×10 块统计生产者占比与宜居度的相关系数：**开耦合 0.648，关耦合 -0.025**。这不是视觉上的“看起来有关系”，是能算出来的空间相关性。

### 6.4 逐格验收

`final_hash` 是最终网格每个格子的状态索引拼成的字节串 crc32。同 seed 同参数必须逐位一致；改一个格子的判定顺序都会变。`ca --check` 先比六个 summary 指标（容差见代码），再比 `final_hash`。

## 9. 已知限制与下一步

1. **没有大气环流与洋流**：温度是纬度辐照 + 海拔 + 简单扩散，季风、厄尔尼诺、西边界流不会自发出现。
2. **没有时间维度**：板块是当前一帧，不能回放几亿年漂移；山脉高度有等ostasy硬上限，但没有均衡回弹。
3. **群系是声明带 + 湿度偏移**，不是 Whittaker 图；农业、城市、道路 suitability 没建模。
4. **降水标定到目标均值**：空间格局是推出来的，总量是设定给定的；换气压会改总量。
5. **跨平台浮点**：同机同 seed 可复算；跨 Python 版本/CPU 的 `sin/cos` 末位差异可能让 `final_hash` 对不上，属已知边界。
6. **交互页不做 3D 球**：正射地球是静态 PNG；可交互的只有 2D 地图。3D 球留给 `preview.html` 的 Three.js 层。

下一步优先级：洋流与雨影的海陆热力差 → 季节相位（而不是年均）→ 冰川/海平面随温度反馈 → 把 `map.html` 的地球做成可旋转的三维球。
