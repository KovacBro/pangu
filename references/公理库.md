## 拼装配方（三例）

**「三阳世界」** = C01 + C02 + P02 + B02 + V01 + V05  
→ 双星给两个影子，第三颗星给永夜里的蓝光；G 衰减让三倍半径可站立；双峰色素响应两种色温；历法锁在互食周期；影子数量成为阶级符号。

**「永夜地热界」** = C05 + P06 + B07 + V02 + K10  
→ 潮汐供暖造出无光生态；熵泵让热量能聚集；群体意识取代个体；时间靠身体；光敏矿石是唯一光源。

**「破碎几何界」** = M01 + M06 + K08 + V04 + C09  
→ 双曲空间让面积指数增长；分形地貌让地图永远画不完；平面分子让生命是薄片；数学停在有限；环世界提供居住带。

## 反面积木（看似酷，实则难救）

| 积木          | 为什么危险            |
| ----------- | ---------------- |
| 魔法/超能力      | 没有代价体系，等于放弃推导    |
| 无限能源        | 抹平一切冲突，故事与生态同时死亡 |
| 时间旅行        | 因果崩塌，审查必挂        |
| "因为神造的就是这样" | 终止解释，不是解释        |
| 平行世界随意穿越    | 稀释每个世界的分量        |

要用也行，但必须给出**比物理更严格的代价**（如：每次施法消耗十年寿命，且不可逆）。
