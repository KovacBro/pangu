# 七斧创世法

> 每一斧都是 **问 → 搜 → 定** 三步。跳过"搜"会产生塑料世界；跳过"问"会造出你不想要的世界；跳过"定"会让设定烂在对话里。

## 全局节奏

```
斧1 混沌    ── 定调：一句话 + 三种可能方向
  ↓（用户点头）
斧2 分判    ── 定"天"：宇宙骨架，能算得出昼夜与季节
  ↓
斧3 立律    ── 定"法"：常数表 + 至少一条改写
  ↓
斧4 炼质    ── 定"料"：物质从哪来，靠什么结合
  ↓
斧5 化生    ── 定"活"：能量怎么流动，生命怎么复制
  ↓
斧6 启智    ── 定"人"：他们怎么知道时间，怕什么
  ↓
斧7 演界    ── 定"史"：审查、修补、3D 呈现、交付
```

**每斧结束必须做一次"用户确认"**，但不要问"这样可以吗"（用户会说可以）。要问**有区分度的问题**：

- ❌ "这个设定可以吗？"
- ✅ "接下来要选：A 让这世界慢慢死去，B 让它周期性重生。你要哪个？"

## 斧 1 · 混沌（Chaos）

**目的**：把模糊意象压成一句可推导的悖论。

### 提问脚本

```
先不用管合不合理，回答我三个问题：

1. 这世界里最怪的一幕是什么？（一个画面，不是设定）
   例："两个人站在山顶，脚下有两个影子，朝相反方向伸出去。"

2. 你希望它给人什么感觉？（三个形容词就够）
   例：辽阔、干渴、庄严

3. 有没有绝对不能出现的东西？
   例：不要魔法、不要外星人、不要蒸汽朋克
```

若用户只给一句话（"造个三倍地球大的双日照地"），直接进入自主模式，自己补 2、3，写成 `meta.aesthetic` 与 `seed.forbidden`，并告知用户"我替你定了这两条，随时可改"。

### 检索（"质感"类）

- `<核心意象> concept art description` — 抓形容词库，用于 `meta.aesthetic`
- `<核心意象> scientific feasibility` — 先摸一下它有多难

### 定

写 `meta` 与 `seed.core_paradox`。**悖论必须是可证伪的陈述句**，不能是抒情。

- ❌ "这是一个充满奇迹的世界"
- ✅ "半径三倍于地球，却仍有固体地表与可呼吸大气"

### 过关标准

写完 `core_paradox` 后自问：**这句话里的两个词，在地球常识下是互相排斥的吗？** 不是排斥的，就不是悖论，是描述。

## 斧 2 · 分判（Dichotomy）

**目的**：定"天"。让昼夜、季节、潮汐、方位可以被算出来。

### 提问脚本

```
关于"天"，三选一（也可以自创）：

A. 有太阳，但不止一个 —— 双日/三阳/伴星
B. 没有太阳 —— 热从地里来、从潮汐来、从上一代文明来
C. 太阳不是恒星 —— 是壳内的灯、是被囚禁的奇点、是活的

选完再回答：这个地方的人，靠什么知道"过了一年"？
```

**这个问题是照妖镜**。答不出"怎么计时"的世界，通常是没想清楚轨道。

### 检索（"锚定 + 证伪"类，两次）

1. **锚定**：`circumbinary planet habitable zone`、`triple star system stability`、`tidal heating Europa Enceladus`、`rogue planet geothermal`
2. **证伪**：`maximum radius rocky planet`、`why super earths become mini neptunes`、`binary star planet orbit instability`

证伪这步极重要。真实约束（例如：岩石行星半径超过约 1.6–2.0 地球半径时，会因吸积气体变成迷你海王星，失去固体表面）正是我们**必须用代价去偿还的债**。

### 推导链

```
恒星质量/光度 → 宜居带位置 → 行星轨道半长轴
双星间距 → 稳定半径下限（≥2.5 倍间距）
光度总和 + 轨道 → 平衡温度 → 是否有液态溶剂
自转 + 倾角 → 昼夜长度、季节强度
行星质量 + 半径 → 重力 → 大气逃逸 → 气压
```

计算全部写进 `physics` 并让 `validate` 复核。**不要凭感觉写"一年 400 天"**，用开普勒第三定律：

```
P² = a³ / (M_star_total)      # P 单位年，a 单位 AU，M 单位太阳质量
```

### 常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| 双星太近而行星太近 | 轨道混沌，几个月就甩飞 | 行星 `a_au` ≥ 2.5 × 双星间距 |
| 三倍半径的岩石行星 | 质量 27 倍地球，吸积成气团 | 降 G、降密度，或改成"三倍表面积"（半径 1.73） |
| 潮汐锁定还写"日出日落" | 一半永昼一半永夜 | 改成"晨昏线文明"，或给偏心轨道造成天平动 |
| 无恒星却温暖 | 热力学凭空来 | 潮汐加热 / 放射性衰变 / 残余地热，必须给功率 |

### 过关标准

能从 `stars[]` 的数值，手算出主角天体的一天与一年，且与 `calendar` 一致。

## 斧 3 · 立律（Nomos）

**目的**：写常数表。这是整个技能的**脊椎**——后面所有斧头都在解释它。

### 提问脚本

```
地球有四条底层规矩，你可以改其中任意几条，但每条都要付账：

1. 引力是吸引的          → 要不要改成排斥/随距离变号？
2. 光速是 30 万 km/s     → 要不要降到能走路的量级？
3. 能量守恒              → 要不要允许局部逆流（熵泵）？
4. 空间是平直三维欧氏的  → 要不要弯曲、分层、加一维？

改哪几条？（也可以说"你定"）
```

### 检索（"取反"类）

- `physics with different gravitational constant consequences`
- `variable speed of light cosmology`
- `hyperbolic space perception`
- `second law of thermodynamics violation local`

这里的检索目的是**拿真实的"如果"研究当弹药**，让自己的改写有学术质感，而不是民科。

### 推导链

每条常数改动，必须填三格：

| 改动 | 后果（连锁） | 代价（可量化） |
|---|---|---|
| G × 0.6 | 表面重力 1.79 g，三倍半径可站立；恒星更"松散" | 星系形成更慢，恒星寿命变短 15% |
| c × 0.001 | 光行差明显，天空有"延迟影像" | 全球通信延迟 3 秒，无法发展远程同步社会 |

**没有第三列的改动，一律删掉。**

### 常见错误

- 改太多：一次改 5 条以上，世界变成无法理解的噪声。**1.0 版最多改 3 条**
- 改了却不用：常数改了但没有任何场景体现。用"痕迹律"检查
- 只改数值不改定律：把 g 改成 1.5 倍不叫新法则，叫换皮

### 过关标准

`physics.new_interactions` 至少 1 条，且这条直接支撑 `seed.core_paradox`。

## 斧 4 · 炼质（Materia）

**目的**：物质层。回答"这世界的东西是什么做的"。

### 提问脚本

```
1. 最硬的物质是什么？它是怎么形成的？
2. 这里最常见的液体是什么？（水？还是别的？）
3. 有没有一种地球上不存在、但这里遍地都是的材料？
```

### 检索

- `silicon based life chemistry possibility`
- `superheavy elements island of stability`
- `room temperature liquid metal`
- `water ice density anomaly alternatives`

### 推导链

```
物理常数 → 元素合成路径 → 元素丰度
元素丰度 → 常见矿物 → 建筑材料 → 文明的技术路径
溶剂 → 溶解能力 → 生化反应类型 → 生命形态
```

**关键洞察**：文明的建筑与工具，应该由"这世界最不缺的东西"决定。地球最不缺硅和铁，所以我们造混凝土和钢。如果你的世界遍地是液态金属，他们的城市会是浇铸出来的。

### 常见错误

- 元素表随便加：加了"振金"却不解释它为什么不衰变
- 化学与生物脱节：写了硅基生命，却仍用"蛋白质"这个词
- 忽略丰度：稀有材料造不出全民城市

### 过关标准

`chemistry.signature_materials` 里至少有一条，能追溯到 `physics` 的某个改动。

## 斧 5 · 化生（Genesis）

**目的**：把"律"变成"活物"。这是最能体现世界独特性的地方，也是最容易露怯的地方。

### 提问脚本

```
1. 生物靠吃什么活着？（能量从哪来，怎么变成可用的）
2. 遗传靠什么？（DNA？还是别的载体）
3. 有没有一种生物，是这个世界的"标志物"？
```

### 检索

- `alternative biochemistry solvents`
- `non DNA genetic information storage`
- `chemoautotroph ecosystem without sunlight`
- `<双星色温> plant color evolution`

### 推导链

```
能量来源（恒星辐照/化学/潮汐）
  → 初级生产者（光合/化能）
  → 能量货币（ATP 类似物）
  → 代谢废物（氧气？硫？甲烷？）
  → 大气成分（与 cosmology.atmosphere 必须一致！）
  → 呼吸者 / 高级消费者
```

**闭环检查**：生物的代谢废物，必须出现在 `atmosphere.composition` 里。地球的氧气是大氧化事件的产物——如果你的世界大气有 19% 氧气，就必然发生过一次全球性光合灾难。

双星世界要额外处理**光谱**：两颗色温不同的恒星，光合色素会演化出双吸收峰。

### 常见错误

| 错误 | 说明 |
|---|---|
| 有氧气却没有产氧生物 | 大气成分是历史遗产，不能凭空存在 |
| 营养级热量不递减 | 每一级约只剩 10%，`trophic_levels[].share` 要体现 |
| 能量货币还是 ATP | 换皮。至少改个名字与化学基础 |
| 生态没有灭绝史 | 加 `mass_extinctions`，世界才有纵深 |

### 过关标准

能画出完整能量流：`辐照 → 生产者 → 消费者 → 分解者 → 回到无机物`，且每一环都有名字。

## 斧 6 · 启智（Anima，可选）

**目的**：有智慧生命才做这斧；纯生态世界可直接跳。

### 提问脚本

```
1. 他们怎么知道"一年过去了"？（天空里有什么周期性现象）
2. 他们的技术跳过了哪个阶段？为什么？
3. 有什么事情，在他们的物理条件下是"绝对做不到"的？
```

第 3 问最出彩。**文明的形状，由它做不到的事定义**，不由它做到的事定义。

### 检索

- `timekeeping without sun`
- `civilization without wheel`
- `how do you build astronomy on a binary star`

### 推导链

```
calendar → 农业节律 → 宗教/历法权力 → 社会结构
物理限制 → 技术树断点 → 独特的替代技术
重力/大气 → 建筑形态、交通方式、身体形态
```

### 常见错误

- 文明与物理无关：明明 1.8 g，却住高楼不加固
- 计时与 calendar 打架：`civilization.timekeeping` 必须能对上 `calendar`
- 社会禁忌无来源：好的禁忌来自物理代价（如"不可直视双星合"因为会灼伤视网膜）

## 斧 7 · 演界（Cosmogony）

**目的**：把静态设定变成有时间纵深的世界，然后过审查。

### 三件事

1. **写历史**：三个纪元（起源 / 灾变 / 当下），一次大灭绝，一个未解之谜
2. **过审查**：逐条跑 `references/自洽性审查协议.md` 的五维十六问
3. **出成品**：`validate` → `preview` → `export`

### 历史推导链

```
物理 → 一次灾变（撞击/恒星活动/轨道迁移）
     → 生态崩溃（mass_extinctions）
     → 幸存者重塑生态位
     → 文明兴起（若有）
     → 当下（用户要讲述的时刻）
```

**未解之谜**要留给用户或玩家探索，不要全部解释完。留白是世界的呼吸。

## 附：三种模式的操作差异

| 模式 | 用户输入 | 你的动作 | 交付速度 |
|---|---|---|---|
| `auto` 全自主 | 一句话 | 七斧全自己定，每斧只汇报结果，允许用户打断 | 最快，一轮可出全套 |
| `co-create` 共创 | 想参与 | 每斧给 2–3 个方案（含代价对比），等选择 | 5–8 轮 |
| `audit` 审计 | 已有构想 | 跳到斧 7，只做审查与修补，不改原意 | 1–2 轮 |

**默认判断**：用户话语中出现"帮我造 / 随便 / 你来定"→ `auto`；出现"我想要 / 我希望 / 能不能"→ `co-create`；出现"看看我这个 / 有什么问题"→ `audit`。
