# 检索与灵感策略

> 检索不是为了"查资料"，是为了**让世界撞上现实的墙**。撞不上的世界是塑料的；撞上了又绕过去的世界，才是盘古要造的。

## 一、四类检索

| 类型 | 目的 | 产出 | 强制次数 |
|---|---|---|---|
| **锚定 Anchoring** | 拿真实数值与机制做参照系 | 常数、量级、已知案例 | 每世界 ≥1 |
| **证伪 Falsification** | 找出"为什么这不行"的硬约束 | 障碍清单 + 需要偿还的债 | 每世界 ≥1（**不可省**） |
| **取反 Inversion** | 找真实极端案例，再推到更极端 | 反常识积木 | 每世界 ≥1 |
| **质感 Texture** | 抓意象、术语、视觉参考 | 形容词、配色、场景描写 | 每世界 ≥1 |

**总计 ≥4 次，且四类各至少一次。** 只做"锚定"的世界会变成维基百科摘抄；只做"质感"的世界会变成空壳美学。

## 三、取反技巧：把真实推到荒诞

这是盘古最核心的检索用法。四步：

```
1. 找一个真实存在的极端案例
   例：开普勒-16b，环双星行星，真实存在

2. 找出它的"限制条件"
   例：轨道半径必须 ≥2.5 倍双星间距，否则不稳定

3. 问：如果把限制条件本身改掉会怎样？
   例：如果这个世界的 G 更小、双星更轻，稳定半径会缩小 → 双星可以贴得更近
       → 天上两个太阳巨大、靠近、互相绕转极快（几天一圈）

4. 补上代价
   例：双星靠近 → 潮汐扰动强 → 行星自转被拖慢 → 一天长达数百小时
       → 昼夜温差极端 → 生物进化出蓄热器官 → 文明夜间活动
```

**成品**：不是"有两个太阳的世界"，而是"两个太阳在头顶互相追逐、一天等于地球一个月、文明在永恒的黄昏里醒来"的世界。

## 四、把检索结果变成设定的三步

看到一条资料，不要抄。走三步：

1. **抽机制**：这条资料背后的物理/化学机制是什么？（一句话）
2. **改参数**：改哪个参数能让机制产生反向结果？
3. **推后果**：改完之后，山、水、生物、文明各会变成什么样？

**反例**（抄）：
> 开普勒-16b 是一颗环双星行星，距离地球约 200 光年，半径约为木星的 0.75 倍……

**正例**（用）：
> 环双星行星的轨道必须远于双星间距的 2.5 倍，这意味着"一年"必然很长。若把双星质量压低、间距缩到 0.2 AU，稳定线降到 0.5 AU，宜居带的"年"仍有 200 天以上——于是这颗行星的历法以"双星互食"（44 天一次）为月，一年正好 4 个多月。

## 五、结果登记规范

所有检索必须落进 `seed.references[]`，四字段：

```jsonc
{
  "title": "Kepler-16b: A Transiting Circumbinary Planet",
  "url": "https://...",           // 无链接可留空，但 title 必须真实
  "takeaway": "环双星行星在稳定轨道上可以长期存在",  // 一句话结论，用自己的话
  "use": "为 C01 积木提供结构合法性；据此把双星间距压到 0.3 AU"  // 我怎么用它
}
```

`use` 字段是关键——**写不出"我怎么用它"，说明这条检索没用，删掉**。

## 六、搜不到怎么办

真实科学常常没有答案（例如"三倍地球半径的岩石行星"根本不存在）。此时切换三种兜底：

| 兜底 | 做法 | 例子 |
|---|---|---|
| **量级估算** | 用基本公式自己算 | `g = GM/r²` 手算表面重力，不查表 |
| **类比迁移** | 找结构相似的系统 | 用"热木星"的潮汐锁定类比"环双星行星"的自转 |
| **显式虚构** | 明说"此处引入新相互作用 X"，并给出代价 | `new_interactions: 潮汐耦合场` |

**显式虚构是合法的**。盘古允许改写物理，但要求改写被**声明**、被**定价**、被**追踪**。偷偷违反物理才是作弊。

## 七、搜够了的判断标准

三条全中就算够：

1. 你能说出这世界**最容易被攻击的一点**，以及你的防守方案
2. 你手上有**至少一个真实存在的近似案例**
3. 你能用一句公式或一个数值，支撑核心悖论的关键环节

做不到，继续搜。

## 八、反模式

| 反模式 | 症状 | 修法 |
|---|---|---|
| 摘抄症 | 设定里出现整段维基句式 | 强制改写为"机制→后果"句式 |
| 权威依赖 | "NASA 说……"，但没说它怎么影响世界 | 补 `use` 字段 |
| 检索代替推导 | 搜完就写，不做连锁推演 | 回到七斧的"推导链"逐格填 |
| 只搜正面 | 全是"可能""或许"，没有硬约束 | 补一次"证伪"类检索 |
| 过度检索 | 搜了 20 次还没动笔 | 上限 8 次，超出即用兜底 |
